## 1. 安裝與第一次開啟

**拿到 `.dmg`（別人給你的）：**

1. 雙擊 `.dmg`，會出現一個視窗：左邊是 App、右邊是 `Applications` 資料夾
2. 把 App 拖進右邊的 `Applications`
3. 第一次開啟：在 `Applications` 裡 **右鍵 →「打開」→ 再按一次「打開」**
   （程式沒有 Apple 付費簽章，macOS 會先擋一次；只需要做一次，之後就能直接雙擊）

**自己編譯：**

```bash
git clone <這個專案>
cd dynwall
./build.sh install        # 裝到 ~/Applications/動態壁紙.app
```

**第一次打開會看到：**

- 一個「壁紙庫」視窗（左邊縮圖、右邊預覽）
- 桌面壁紙預設套用內建的「極光」動態壁紙
- 選單列多一個 🖼 圖示（位置在右上角、靠近控制中心那側）

> ⚠️ 如果你的 macOS 把選單列設成「自動隱藏」，平常看不到圖示 —— **把滑鼠移到螢幕最上面**，選單列就會出現。

## 2. 介面在哪裡

| 東西 | 位置 |
|---|---|
| 壁紙庫（主要介面） | 雙擊 App，或選單列 🖼 →「開啟壁紙庫…」（⌘L） |
| 選單列圖示 | 螢幕最上面的選單列，右側 |
| 設定檔 | `~/Library/Application Support/動態壁紙/config.json` |
| 壁紙庫資料夾 | `~/Library/Application Support/動態壁紙/library/` |
| 自訂 HTML 壁紙 | `~/Library/Application Support/動態壁紙/wallpapers/` |
| 設定視窗 | 壁紙庫右上角的 ⚙，或選單列 🖼 →「設定…」（⌘,） |
| 使用導覽 | 選單列 🖼 →「顯示使用導覽…」，或壁紙庫右上角的 `?` |
| 日誌 | `~/Library/Logs/動態壁紙.log` |

關掉壁紙庫視窗後，程式仍在背景運作（Dock 圖示會消失）；再點一次選單列圖示或再雙擊 App 就會回來。

## 3. 換壁紙（三種方法）

**方法 A：壁紙庫（最直覺）**

1. 左邊點一個縮圖（右邊會即時預覽，影片會直接播、HTML 動畫會直接跑）
2. 按右邊的 **套用到桌面**
3. 正在用的那張會標「使用中」

**方法 B：選單列**

選單列 🖼 →「內建動態壁紙」→ 選一個（極光 / 星海 / 賽博格柵 / 數位雨 / 自訂範本）

**方法 C：命令列**

```bash
"/Applications/動態壁紙.app/Contents/MacOS/DynWall" --set video "/path/clip.mp4"
"/Applications/動態壁紙.app/Contents/MacOS/DynWall" --set builtin starfield
```

> ⚠️ **同一個時間只能有一支壁紙 App 在跑。** 如果你之前拿過「把某支影片包成獨立 App」的版本，
> 兩支同時開會有兩層壁紙疊在一起（後開的蓋在上面），看起來就像「壁紙自己變回去了」。
> 確認方法：終端機 `pgrep -fl DynWall` 應該只有一個；`ls ~/Library/LaunchAgents/` 也只該有一個壁紙的自啟設定。

---

### 3-1 內建精選 9 張（NASA・公有領域）

壁紙庫最前面有 9 張「NASA・〇〇」，是 4K 靜態圖：星雲、地球、極光、星系、月球、火星、海洋、
城市夜景、喜馬拉雅。全部來自 NASA Image and Video Library，屬**公有領域**，可以自由使用與再散布，
逐張出處寫在 `resources/wallpapers/static/CREDITS.md`。想換掉或增加，用
`python3 tools/fetch_wallpapers.py 12` 重新抓（每個主題抓一張，保持多樣）。

## 4. 加入自己的影片、圖片、GIF、HTML

**方法 A：按「＋加入壁紙」**

右下角（或標題列）的 **＋加入壁紙** → 選檔案：

| 類型 | 可以選什麼 |
|---|---|
| 影片 | `.mp4` `.mov` `.m4v` |
| 圖片 | `.jpg` `.png` `.heic` `.webp` |
| GIF | `.gif`（會動） |
| HTML | **資料夾**（裡面要有 `index.html`） |

**方法 B：拖檔案進視窗**

直接把檔案從 Finder 拖到壁紙庫視窗上，效果一樣。

**為什麼要「加入」而不是直接指定桌面上的檔案？**

macOS 的隱私權限（TCC）不讓非沙盒程式讀取「桌面」「文件」「下載」裡的檔案。
「加入壁紙」會**複製一份到壁紙庫資料夾**（`~/Library/Application Support/動態壁紙/library/`），
之後就完全沒有權限問題，而且原始檔不會被動到。

**刪除**：縮圖右下角的 🗑（內建壁紙不能刪）。刪除只影響壁紙庫裡的那份複本。

---

### 4-3 匯入 Wallpaper Engine 網頁壁紙

如果你手上是 Wallpaper Engine 的**網頁型**（`project.json` 裡 `"type": "web"`）壁紙：

1. 選單列 🖼 →「**匯入 Wallpaper Engine 網頁壁紙…**」
2. 選那個資料夾裡的 `project.json`（也可以直接選資料夾）
3. 整個專案會被**複製**進壁紙庫，之後原本的資料夾可以刪掉
4. 壁紙庫會多一張，按「套用到桌面」

限制：Wallpaper Engine 的「屬性面板」與「音訊視覺化」不支援，腳本會拿到預設值；
`type` 是 `scene`（3D）或 `video` 的專案不吃，請直接選那個 `video` 檔加進來。

## 5. 調整設定

在壁紙庫右側面板（或選單列 → 選項）：

| 設定 | 作用 |
|---|---|
| 播放中 / 暫停 | 影片暫停、HTML 動畫凍結 |
| 靜音 | 影片壁紙要不要出聲（預設靜音） |
| 速度 | 0.5× ～ 2× |
| 暗化 | 把壁紙壓暗，桌面圖示比較清楚 |
| 畫面縮放 | 填滿（可能裁切）／完整顯示（可能留黑邊） |
| 允許滑鼠互動 | 只有自訂 HTML 壁紙需要 |
| 開機自動啟動 | 登入後自動開始跑壁紙 |
| 關掉 App 後保留桌面 | 結束時把當下畫面留在桌面。**關掉的話，結束時會還原你原本的桌布** |
| 鎖定畫面顯示當下畫面 | 打密碼那個畫面系統只認「桌布圖」，所以進鎖定前會先抓一張當下畫面當桌布；想看自己原本的桌布就關掉它 |
| 視差（景深） | 滑鼠移動時壁紙跟著位移，0–30px。**預設關閉**，開了會先放大所以不會露黑邊 |
| 定時自動換壁紙 | 每 5 分鐘／15 分鐘／30 分鐘／1 小時／3 小時，換壁紙庫裡的下一張 |
| 全螢幕時暫停 | 前景 App 鋪滿螢幕（看片、玩遊戲）時把壁紙停住，省電也省顯卡 |

> 設定頁的每一顆開關上面都有**標題**、下面有一行**說明**；如果你只看到兩顆膠囊、沒有字，
> 那是舊版。更新到最新版就會看到說明文字。

---

### 5-1 鎖定畫面也變成動態（勾一次就好）

打密碼的畫面是**系統**畫的，第三方 App 不能在那裡開視窗；macOS 26 唯一能讓它動的方法，是換掉系統「動態桌布（aerial）」的影片檔 —— 這件事 App 會自己做。

1. 壁紙庫 → ⚙ 設定 → **播放 → 鎖定畫面（一鍵）** → 打開「**鎖定畫面跟桌面一起動態**」
2. 如果系統還沒有任何動態桌布，App 會**自動幫你打開「桌布」設定頁**；隨便選一個會動的桌布，等它下載完
3. 下載完 **不用再按任何東西** —— App 每 4 秒檢查一次，看到就自動轉檔、換進去、重啟 `WallpaperAgent`
4. 按 **Ctrl+Cmd+Q** 鎖定看看

之後每次換壁紙都會自動同步：**第一次轉檔約 15–20 秒，之後同一支影片只要 1 秒**（轉好的存在 `~/Library/Application Support/動態壁紙/lockvideo/`）。

- 原始 Apple 影片會先備份，設定裡按「還原 Apple 影片」可以放回去
- 只有**影片**壁紙能同步；HTML／圖片要用錄影或轉檔做成影片
- 桌面桌布要保持是「動態」，鎖定畫面才會播這支

## 6. 自訂 HTML 動態壁紙（重點）

### 6-1 取得可編輯的範本

選單列 🖼 → 我的自訂壁紙 → **複製內建壁紙成可編輯範本**
（或命令列 `DynWall --copy-templates`）

範本會出現在：

```
~/Library/Application Support/動態壁紙/wallpapers/極光（可編輯）/index.html
```

### 6-2 改它，存檔，桌面立刻變

用任何文字編輯器（VS Code、CotEditor、內建「文字編輯」都可以）打開 `index.html`，
**存檔的瞬間桌面就會更新**，不用重開 App。

每個範本開頭都有一段中文註解的 `CONFIG`，改數字就好：

```js
const CONFIG = {
  動畫速度: 0.7,                                  // 越大動得越快
  光帶數量: 3,                                    // 1～6 層
  顏色:     ['#22d3ee', '#34d399', '#a78bfa'],    // 每層顏色 #rrggbb
  星星數量: 160,
  輝光強度: 0.55
};
```

### 6-3 從零寫一個

拿「自訂範本（可編輯）」當起點，裡面每一行都有中文註解，包含：
Canvas 2D 畫圖、放自己的圖片、滑鼠互動。

同一個資料夾可以放圖片、字型、`.css`、`.js`，用相對路徑引用，例如 `url('bg.jpg')`。

### 6-4 三個常見坑

1. **不要依賴網路**（CDN 的 Three.js 之類）—— 壁紙載入時可能沒網路，而且慢
2. **不要寫 `document.hidden` 判斷** —— 壁紙視窗被其他視窗遮住時 WebKit 會回報 hidden，你的動畫會自己停掉
3. Canvas 尺寸請用 `window.innerWidth/innerHeight` 並監聽 `resize`，不要寫死像素

## 7. 影片壁紙的建議規格

| 項目 | 建議 |
|---|---|
| 解析度 | 1080p 就好；4K 60fps 會讓 CPU 跑到 5～10%，筆電很耗電 |
| 幀率 | 30 或 60fps 都可以 |
| 編碼 | H.264（`avc1`）最保險，HEVC 也可以 |
| 音軌 | 建議移除（壁紙預設靜音，留著只是浪費） |
| 長度 | 越短越省電；10～20 秒循環最舒服 |
| 內容 | 最好做「首尾接得起來」的循環，不然每圈會跳一下 |

用 `ffmpeg` 轉成適合的規格（如果機器有裝）：

```bash
ffmpeg -i input.mov -an -vf "scale=-2:1080" -c:v libx264 -crf 20 -preset slow -pix_fmt yuv420p loop.mp4
```

（`-an` = 去掉音軌）

## 8. 打包成獨立 App 分享給別人

```bash
./build-standalone.sh "我的壁紙" "mywall" "/path/to/clip.mp4" "我的壁紙"
#                     ↑App 名稱   ↑識別碼後綴   ↑媒體檔          ↑顯示標題
```

產出 `~/Applications/我的壁紙.app`（影片包在 App 內部）與一個可分享的 `.zip`。

再做成一張拖曳安裝的 DMG：

```bash
./build-dmg.sh "$HOME/Applications/我的壁紙.app" "我的壁紙"
```

對方拿到之後：解壓 → **右鍵 →「打開」→ 再按一次「打開」**（沒有付費簽章，macOS 會先擋一次）。

> ⚠️ **素材版權**：這個工具只負責打包，不會替你取得影片／圖片的授權。
> 包商業遊戲或動畫的影片再散布，是侵權行為，跟程式碼的授權無關。

## 9. 開機自動啟動 / 結束 / 解除安裝

- **開機自動啟動**：壁紙庫右側面板打開「開機自動啟動」，或選單列 → 選項 → 開機自動啟動
- **結束程式**：選單列 🖼 →「結束動態壁紙」（桌面會留著最後一格）
- **解除安裝**：
  ```bash
  rm -rf ~/Applications/動態壁紙.app \
         ~/Library/Application\ Support/動態壁紙 \
         ~/Library/Caches/動態壁紙 \
         ~/Library/LaunchAgents/com.dynwall.app.plist
  ```

## 10. 常見問題

| 症狀 | 原因與解法 |
|---|---|
| 換了壁紙但桌面沒變 | ① 有沒有按「套用到桌面」？② 是不是有**兩支**壁紙 App 在跑（`pgrep -fl DynWall`） |
| 桌面變成一張靜止的圖 | 那是「關掉 App 後桌面保留同一張」的靜態海報，不是壞了；重新開啟 App 就會動 |
| 壁紙狂閃 | 有東西在反覆重建壁紙（日誌會連續出現 `APPLY`）。回報 Issue 並附日誌 |
| 蓋上筆電再打開就不動了 | 已內建每 3 秒自查螢幕／鎖定狀態；若仍發生，附日誌回報 |
| 影片選了但畫面全黑 | 檔案讀不到（TCC）或編碼不支援 → 用「＋加入壁紙」複製一份再試；或先轉成 H.264 |
| 全螢幕 App 看不到壁紙 | 正常，macOS 的全螢幕是另一個桌面 |
| 找不到選單列圖示 | 選單列可能設成自動隱藏 → 滑鼠移到螢幕最上面 |
| 很耗電 / 風扇很吵 | 換 1080p 影片、降速度、加暗化，或改用元素少的內建壁紙 |
| 桌面圖示看不清楚 | 把「暗化」調高一點 |
| 壁紙庫的縮圖是黑的 | 少了縮圖檔；重新編譯（`./build.sh`）會重做，或直接無視（只影響縮圖） |

## 11. 遇到問題要附什麼

開 Issue 時請附上：

1. macOS 版本（例：macOS 26.4）與 CPU（Apple Silicon / Intel）
2. 壁紙類型（影片 / 圖片 / GIF / HTML）與大概規格
3. 日誌：`~/Library/Logs/動態壁紙.log`（最近的 50 行就夠）
4. 發生前你做了什麼（換壁紙？蓋上蓋子？切換全螢幕？）

日誌裡重要的關鍵字：`APPLY`（重建內容）、`SCREEN-SYNC`（螢幕參數變更）、
`POSTER`（寫系統桌布）、`HEALTH`（睡眠／鎖定自查）、`SYSTEM-PAUSE`（暫停／恢復）。
