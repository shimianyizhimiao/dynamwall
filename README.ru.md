# 動態壁紙 · DynWall

**Только для macOS** · macOS 13+ · Apple Silicon и Intel · Swift + AppKit · без сторонних зависимостей

> ⚠️ **Личный проект — ошибки возможны.** Проверено только на macOS 26.4 / Apple Silicon.
> Если что-то не работает, создайте Issue, указав версию macOS и лог `~/Library/Logs/動態壁紙.log`.

Нативный движок анимированных обоев для macOS: **видео, GIF, изображения или собственный HTML/CSS/JS**
рисуются **поверх системных обоев и под значками рабочего стола** — значки, контекстное меню,
перетаскивание и Mission Control продолжают работать. Есть графическая библиотека обоев.

Подробная инструкция: [docs/使用說明.md](docs/使用說明.md) (на китайском).

## Возможности

- **Четыре источника**: видео (бесшовный цикл через `AVPlayerLooper`), изображения, GIF, свой HTML/CSS/JS
- **Горячая перезагрузка HTML**: сохранили файл — рабочий стол обновился сразу
- **Библиотека обоев**: миниатюры, живой предпросмотр, панель настроек, перетаскивание файлов
- **Управление в строке меню**: смена обоев, пауза, затемнение, скорость, автозапуск
- **После выхода ничего не теряется**: текущий кадр сохраняется как обои рабочего стола
- **Упаковка**: видео → отдельное приложение `.app`, затем `.dmg` с перетаскиванием
- **4 встроенных** canvas-обоев (сияние / звёздное море / киберсетка / цифровой дождь)

## Требования

- macOS 13 Ventura или новее (Apple Silicon или Intel)
- Xcode Command Line Tools — `xcode-select --install`
- Опционально: Google Chrome (безголовый рендер миниатюр и постеров)

## Сборка и установка

```bash
git clone https://github.com/shimianyizhimiao/dynwall.git
cd dynwall
./build.sh            # создаёт build/動態壁紙.app
./build.sh install    # устанавливает в ~/Applications
```

Подпись ad-hoc — аккаунт Apple Developer не нужен.

## Использование

1. Откройте `~/Applications/動態壁紙.app` → библиотека обоев
2. Выберите миниатюру → **Применить к рабочему столу**
3. **＋ Добавить обои** — видео / изображение / GIF / папка HTML (или перетащите файлы)
4. Значок в строке меню (наведите курсор вверх экрана) → смена / пауза / библиотека (⌘L)

CLI: `DynWall --set video "/путь/clip.mp4"` · `--set builtin starfield` · `--autostart on`

`arm64` и `x86_64` собираются с целевой версией macOS 13.

## Известные проблемы

- Используется приватная настройка WebKit (`pageVisibilityBasedProcessSuppressionEnabled`) → **нельзя публиковать в App Store**
- Мультимониторная поддержка базовая и плохо проверена
- Обои-видео 4K 60 fps ≈ 5–10% CPU; на ноутбуках лучше 1080p
- Одновременно может работать только одно приложение обоев
- Полноэкранные приложения закрывают обои (обычное поведение macOS)
